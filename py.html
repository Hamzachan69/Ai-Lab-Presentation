SECTION 02

The Great Translation: C++ vs Python Syntax

You already know how to think like a programmer. Python just lets you express those thoughts with less typing and fewer compiler errors. Let's see the key translations!

Figure 2: Side-by-side syntax comparison - your translation cheat sheet!

🔄 Key Differences at a Glance

❌ C++ Way (What You Know)

  • Type declarations required: int x = 5;
  • Semicolons mandatory everywhere
  • Curly braces { } for blocks
  • #include headers needed
  • std:: namespace prefix
  • Fixed array sizes or vectors

✅ Python Way (Your New Best Friend)

  • No types needed: x = 5
  • No semicolons (optional)
  • Colons + indentation define blocks
  • Built-in functions always available
  • Clean namespace, no prefixes
  • Dynamic lists by default
⚠️ Important Note About Indentation

In Python, indentation is NOT optional. It replaces curly braces. Use 4 spaces (not tabs). Your code won't run if indentation is wrong. Yes, whitespace has power here!

Variables and Dynamic Typing

Python uses dynamic typing. You don't declare types; Python figures them out automatically. Variables are like shape-shifters compared to C++'s strict casting.

Figure 3: Automatic type detection and conversion examples

📊 Type System Examples

# Python figures out the type automatically
name = "FAST NUCES"       # str
semester = 6              # int
gpa = 3.75                # float
is_passed = True          # bool (capital T/F!)
courses = ["AI", "DB", "OS"]  # list
student = {"name": "Ali", "roll": "21P-0001"}  # dict

# Type checking
print(type(gpa))           # 
print(isinstance(semester, int))  # True

# Type conversion (casting)
x = int("42")      # str to int

z = float("2.5")    # str to float
🤯 Mind-Blowing Feature: Variables Can Change Type!

Variables can change type mid-program. This is perfectly legal in Python:

x = "hello"   # x is now a string (completely legal!)
x = [1, 2, 3] # x is now a list

SECTION 04

Strings: Your New Superpower

Forget char arrays and string.h. Python strings are objects with built-in superpowers. F-strings alone are worth the switch!

Figure 4: Comprehensive string methods demonstration

⭐ F-Strings: Formatted String Literals

Your new best friend for output formatting:

name = "Hamza"
course = "AI Lab"

# F-string formatting (Python 3.6+)
print(f"Welcome to {course}, taught by {name}!")
# Output: Welcome to AI Lab, taught by Hamza!

# Expressions inside braces work too!
print(f"Next year: {2024 + 1}")
# Output: Next year: 2025

🔧 Built-in String Methods (No Include Needed!)

msg = "   Hello FAST NUCES   "

# Basic operations
print(msg.strip())           # Removes whitespace → "Hello FAST NUCES"
print(msg.lower())           # → "   hello fast nuces   "
print(msg.upper())           # → "   HELLO FAST NUCES   "
print(msg.replace("FAST", "SPEED"))  # → "   Hello SPEED NUCES   "

# Slicing (C++ has no equivalent this clean!)
text = "PYTHON"
print(text[0:3])     # "PYT" (start:end, end excluded)
print(text[::-1])    # "NOHTYP" (reversed!)
print(text[::2])     # "PTO" (every 2nd character)

# Split and Join (essential for data processing)
csv_line = "Ali,21P-0001,3.5"
parts = csv_line.split(",")     # ["Ali", "21P-0001", "3.5"]
rejoined = " | ".join(parts)    # "Ali | 21P-0001 | 3.5"
✨ Why Strings Are Amazing in Python
  • ▸ No memory management needed (unlike C strings)
  • ▸ Immutable but easy to create new versions
  • ▸ Unicode support built-in (no wchar_t headaches)
  • ▸ Method chaining: msg.strip().lower().replace("x", "y")
SECTION 05

Control Flow: Same Logic, Less Typing

The logic you learned in C++ is identical. Only the syntax changes - and it's much cleaner. No parentheses around conditions, colons instead of braces!

Figure 5: if/elif/else, loops, and iteration patterns

🔀 Conditional Statements: if / elif / else

grade = 85

if grade >= 90:
    print("A grade - Excellent!")
elif grade >= 80:
    print("B grade - Good job!")
elif grade >= 70:
    print("C grade - Keep going!")
else:
    print("Needs improvement")

# Notice: No parentheses around conditions
# Notice: Colons after each condition
# Notice: Indentation defines the block

🔄 Loops: For and While

# For loop with range()
for i in range(5):           # 0, 1, 2, 3, 4
    print(i)

for i in range(2, 10, 3):    # 2, 5, 8 (start, stop, step)
    print(i)

# For loop over a list directly (no index needed!)
courses = ["AI", "DB", "Networks"]
for course in courses:
    print(f"I am taking {course}")

# While loop
count = 0
while count < 5:
    print(count)
    count += 1  # NOTE: No count++ in Python!
⚠️ Critical Difference: No Increment Operators

Python doesn't have ++ or -- operators. Always use count += 1 or count -= 1.

SECTION 06

Data Structures Part 1: Lists (Like C++ Vector, But Better)

Forget implementing your own linked list or hash map. Python gives you powerful built-in data structures that just work. Lists are dynamic arrays - much cleaner than C++ vectors!

Figure 6: List manipulation methods demonstrated

📦 Core List Operations

# Create a list
marks = [85, 92, 78, 95, 88]

# Add elements
marks.append(91)        # Add to end → [85, 92, 78, 95, 88, 91]
marks.insert(0, 100)    # Insert at index 0 → [100, 85, 92, 78, 95, 88, 91]

# Remove elements
marks.pop()             # Remove last element → returns 91
marks.pop(0)            # Remove element at index 0 → returns 100

# Sorting and slicing
marks.sort()            # Sort in-place → [78, 85, 88, 92, 95]
print(marks[1:4])       # Slicing → [85, 88, 92] (indices 1, 2, 3)
print(len(marks))       # Length → 5
✨ Lists vs C++ Vectors: Key Advantages
  • ▸ No template syntax: marks = [85, 92, 78] vs vector<int> marks;
  • ▸ Dynamic by nature - no size declaration needed
  • ▸ Mixed types allowed (though not recommended for clarity)
  • ▸ Rich built-in methods for common operations
  • ▸ Slicing syntax is incredibly powerful

Data Structures Part 2: Dictionaries, Tuples, Sets

Three more essential data structures that make Python incredibly expressive. Each serves a specific purpose and makes certain operations trivial.

Figure 7: Dictionaries, tuples, and sets in action

📖Dictionaries

Like C++ map but simpler. Key-value pairs with {} syntax:

student = {
    "name": "Ali Khan",
    "roll": "21P-0042",
    "gpa": 3.6,
    "courses": ["AI", "DB"]
}

# Access by key
print(student["name"])        # "Ali Khan"

# Add new key
student["semester"] = 6

# Safe access with default
print(student.get("age", "N/A"))  # "N/A"

🔒Tuples

Immutable lists - can't change after creation:

coordinates = (33.99, 71.51)  # Peshawar coordinates!

# Great for fixed data
rgb_color = (255, 128, 0)

# ERROR! Tuples can't change
# coordinates[0] = 34.0  # TypeError!

# Perfect for returning multiple values
return (min_val, max_val, avg)

🎯Sets

Collections of unique elements. Duplicate removal automatic!

skills = {"Python", "C++", "Python"}  # Duplicate removed!
print(skills)  # {"Python", "C++"}

# Set operations
set_a = {1, 2, 3, 4}
set_b = {3, 4, 5, 6}
print(set_a | set_b)  # Union: {1, 2, 3, 4, 5, 6}
print(set_a & set_b)  # Intersection: {3, 4}

Functions: Clean, Flexible, Powerful

Functions in Python are first-class citizens. They're cleaner, more flexible, and can do things C++ functions struggle with (like returning multiple values easily).

Figure 8: Default arguments, multiple returns, and lambdas

📝Basic Function Definition

def greet(name):
    return f"Salam, {name}! Welcome to AI Lab."

print(greet("Ali"))  # Salam, Ali! Welcome to AI Lab.

🎯Default Arguments

def calculate_grade(marks, total=100):
    percentage = (marks / total) * 100
    if percentage >= 90: return "A"
    elif percentage >= 80: return "B"
    elif percentage >= 70: return "C"
    else: return "F"

# Uses default total=100
print(calculate_grade(85))

# Custom total
print(calculate_grade(42, 50))

🎁Multiple Return Values (C++ Can't Do This Easily!)

def get_stats(numbers):
    return (min(numbers), 
            max(numbers), 
            sum(numbers)/len(numbers))

low, high, avg = get_stats([85, 92, 78, 95, 88])
print(f"Min: {low}, Max: {high}, Avg: {avg:.2f}")

⚡Lambda Functions (Anonymous Functions)

# Lambda: one-line anonymous function
square = lambda x: x ** 2
print(square(5))  # 25

# Common use case: sorting with custom key
students = [("Ali", 3.5), ("Sara", 3.8), ("Ahmed", 3.2)]
students.sort(key=lambda s: s[1], reverse=True)
# Sorted by GPA descending

List Comprehensions: One Line to Rule Them All

This is where Python starts to feel like magic. List comprehensions let you create and transform lists in single, readable lines. Once you learn this, you'll never go back to verbose for-loops for simple transformations!

Figure 9: Traditional loops vs comprehensions comparison

🔄Traditional Loop vs Comprehension

# Traditional way (C++ thinking) - 3 lines
squares = []
for i in range(10):
    squares.append(i ** 2)

# Python way (list comprehension) - 1 line!
squares = [i ** 2 for i in range(10)]

# Result: [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

🎯Conditional Filtering

# Only even squares
even_squares = [i ** 2 for i in range(10) if i % 2 == 0]
# Result: [0, 4, 16, 36, 64]

# Filter passing scores
scores = [45, 67, 82, 91, 55, 73, 88]
passed = [s for s in scores if s >= 60]
# Result: [67, 82, 91, 73, 88]

🔲Nested & Dictionary Comprehensions

💡 Why Use Comprehensions?
  • ▸ More readable and concise than loops
  • ▸ Often faster than equivalent for-loops
  • ▸ Pythonic idiom - other developers expect it
  • ▸ Reduces boilerplate significantly
  • ▸ Essential for data science and ML workflows

SECTION 11

Object-Oriented Programming: C++ Classes, Python Style

Last lab, you survived the Python basics. Today we level up! Think of Lab 1 as learning to walk. Today, you learn to fly... and then land safely on an AI project. Same OOP concepts you know from C++, but with much cleaner syntax!

Figure 11: Student class demonstrating Python OOP syntax

🏗️Class Definition Basics

class Student:
    # Constructor (__init__ = C++ constructor)
    def __init__(self, name, roll, gpa=0.0):
        self.name = name      # public attribute
        self.roll = roll      # public attribute
        self._gpa = gpa       # _ prefix = private (convention)
    
    # Method (self = C++ this pointer, but explicit)
    def display(self):
        print(f"Student: {self.name} ({self.roll}) - GPA: {self._gpa}")

# Creating objects
s1 = Student("Ali", "21P-0001", 3.8)
s1.display()

🎛️Property Decorators (@property, @setter)

Like C++ getters/setters but Pythonic:

@property
def gpa(self):
    return self._gpa

@gpa.setter
def gpa(self, value):
    if 0 <= value <= 4.0:
        self._gpa = value
    else:
        raise ValueError("GPA must be between 0 and 4.0")

# Usage
print(s1.gpa)        # Calls getter
s1.gpa = 3.9         # Calls setter with validation
✅ Key OOP Differences from C++
  • ▸ No header files or source file separation
  • ▸ No semicolons after class/method definitions
  • ▸ self parameter is explicit (no hidden this pointer confusion)
  • ▸ Public attributes by default (__ prefix for name mangling)
  • ▸ Decorators provide clean syntax for common patterns
  • ▸ Duck typing instead of strict type checking
SECTION 12

Inheritance, Polymorphism & Error Handling

Two critical advanced topics: how to build class hierarchies (inheritance) and how to handle errors gracefully (exceptions). Both concepts exist in C++, but Python's implementation is notably cleaner.

Figure 12: Person base class with Student subclass

🧬Inheritance & Polymorphism

class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def introduce(self):
        return f"I am {self.name}, age {self.age}"

class Student(Person):  # Student inherits from Person
    def __init__(self, name, age, roll):
        super().__init__(name, age)  # Call parent constructor
        self.roll = roll
    
    def introduce(self):  # Override (polymorphism)
        return f"{super().introduce()}, Roll: {self.roll}"

class TeachingAssistant(Student):  # Multiple inheritance OK!
    def __init__(self, name, age, roll, course):
        super().__init__(name, age, roll)
        self.course = course

ta = TeachingAssistant("Ahmed", 23, "21P-0005", "AI Lab")
print(isinstance(ta, Person))    # True
print(isinstance(ta, Student))   # True

Figure 13: try/except blocks and custom exceptions

⚠️Error Handling: try/except (C++ try/catch Equivalent)

# Basic exception handling
try:
    number = int(input("Enter a number: "))
    result = 100 / number
    print(f"Result: {result}")
except ValueError:
    print("That's not a valid number!")
except ZeroDivisionError:
    print("Can't divide by zero!")
except Exception as e:
    print(f"Something went wrong: {e}")
finally:
    print("This always executes (like C++ destructor)")

# Custom exception (like C++ custom exception class)
class InvalidGPAError(Exception):
    def __init__(self, gpa):
        self.gpa = gpa
        super().__init__(f"Invalid GPA: {gpa}. Must be 0.0-4.0")

def set_gpa(gpa):
    if not 0 <= gpa <= 4.0:
        raise InvalidGPAError(gpa)
    return gpa
💡 EAFP Philosophy

Python encourages "Easier to Ask Forgiveness than Permission" (EAFP). Instead of checking if something will work before doing it (LBYL - Look Before You Leap), just try it and handle exceptions. This leads to cleaner, more readable code!

File I/O: Reading and Writing Data

AI is all about data. You need to read CSVs, process text files, and save results. Python makes file I/O trivially easy compared to C++ fstream complexity. Master this - you'll use it constantly in AI projects!

Figure 14: Writing, reading, and CSV processing demonstrations

✍️Writing Files

# Writing to a file (context manager = auto-close!)
with open("students.txt", "w") as f:
    f.write("Name, Roll, GPA\n")
    f.write("Ali, 21P-0001, 3.8\n")
    f.write("Sara, 21P-0002, 3.9\n")
# File auto-closes! (like RAII in C++)

📖Reading Files

# Reading line-by-line
with open("students.txt", "r") as f:
    header = f.readline()  # Read first line
    for line in f:        # Iterate remaining lines
        parts = line.strip().split(", ")
        print(f"Student: {parts[0]}, GPA: {parts[2]}")

# Reading entire file at once
with open("students.txt", "r") as f:
    content = f.read()      # Entire file as string
    lines = f.readlines()   # List of all lines

📊CSV-Style Processing

import csv

with open("data.csv", "r") as f:
    reader = csv.DictReader(f)  # Auto-parses headers!
    for row in reader:
        print(row["name"], row["gpa"])
✨ Why Context Managers (with statement)?
  • ▸ Automatically closes files (even if exceptions occur)
  • ▸ Prevents resource leaks
  • ▸ Cleaner than manual open()/close()
  • ▸ Pythonic best practice - always use with files!
SECTION 14

NumPy: The Foundation of AI in Python

NumPy (Numerical Python) is THE library that makes Python viable for AI. Every ML/AI library (TensorFlow, PyTorch, scikit-learn) is built on NumPy. It provides fast array operations (50-100x faster than Python lists) using optimized C code under the hood.

Figure 15: Array creation and basic operations

🔢Array Creation

import numpy as np

# Creating arrays
a = np.array([1, 2, 3, 4, 5])        # 1D array
b = np.array([[1, 2, 3], [4, 5, 6]])  # 2D array (matrix)

# Special arrays
zeros = np.zeros((3, 3))    # 3x3 matrix of zeros
ones = np.ones((2, 4))     # 2x4 matrix of ones
identity = np.eye(3)        # 3x3 identity matrix
rand = np.random.rand(3, 3) # 3x3 random matrix
rng = np.arange(0, 10, 0.5) # [0, 0.5, 1.0, ..., 9.5]

Figure 16: Matrix operations, statistics, and boolean indexing

⚡Array Operations (Element-wise by Default!)

x = np.array([1, 2, 3])
y = np.array([4, 5, 6])

print(x + y)       # [5, 7, 9] (NO LOOPS NEEDED!)
print(x * y)       # [4, 10, 18]
print(x ** 2)      # [1, 4, 9]
print(np.dot(x, y)) # 32 (dot product)

📐Matrix Operations

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

print(A @ B)              # Matrix multiplication
print(np.linalg.inv(A))    # Matrix inverse
print(np.linalg.det(A))    # Determinant
print(A.T)                 # Transpose

📊Statistical Operations & Boolean Indexing

data = np.array([85, 92, 78, 95, 88, 76, 91])

# Statistics
print(f"Mean: {np.mean(data):.2f}")
print(f"Std Dev: {np.std(data):.2f}")
print(f"Max: {np.max(data)}, Min: {np.min(data)}")

# Boolean indexing (filtering) - SUPER POWERFUL!
passed = data[data >= 80]  # Only scores >= 80
print(passed)  # [85, 92, 95, 88, 91]
🧠 Why NumPy Matters for AI

Neural networks are literally matrix multiplications chained together! NumPy makes these operations 50-100x faster than Python lists because it uses optimized C code under the hood. Think of it as having C++ speed with Python convenience. When you build neural networks later, every layer operation is just NumPy matrix math!

SECTION 15

Functional Programming: map, filter, reduce

These functions are heavily used in AI data preprocessing pipelines. They let you transform data without writing explicit loops - very Pythonic approach that produces clean, elegant code.

Figure 17: map, filter, reduce demonstrations

🗺️MAP - Apply Function to Every Element

temps_celsius = [0, 20, 37, 100]

# Convert Celsius to Fahrenheit
temps_fahrenheit = list(map(
    lambda c: (c * 9/5) + 32, 
    temps_celsius
))
# Result: [32.0, 68.0, 98.6, 212.0]

🔍FILTER - Keep Elements That Satisfy Condition

scores = [45, 67, 82, 91, 55, 73, 88]

# Keep only passing scores (>= 60)
passed = list(filter(lambda s: s >= 60, scores))
# Result: [67, 82, 91, 73, 88]

📦REDUCE - Accumulate Values (Fold Operation)

from functools import reduce

numbers = [1, 2, 3, 4, 5]

# Calculate product of all numbers
product = reduce(lambda a, b: a * b, numbers)
# Result: 120 (1*2*3*4*5)

Figure 18: Real-world data cleaning pipeline example

🔗Chaining: Data Cleaning Pipeline

raw_data = ["  Ali ", "SARA", " ahmed  ", "", "Zain"]

# Clean dataset in one pipeline!
clean = list(
    filter(
        None,  # Remove empty strings
        map(
            lambda s: s.strip().title(),  # Strip & capitalize
            raw_data
        )
    )
)
# Result: ["Ali", "Sara", "Ahmed", "Zain"]

# Read this as: filter(None, map(transform, data))
# Data flows right-to-left through transformations
💡 When to Use Functional Programming?
  • ▸ Data preprocessing pipelines (very common in ML)
  • ▸ Transformations on collections
  • ▸ When you want to avoid explicit loops
  • ▸ Chaining multiple operations together
  • ▸ Making code more declarative (what, not how)
